# Симулятор мікроконтролера

Кросплатформна версія навчального симулятора 15-бітної машини фон Неймана до лабораторної роботи №1 з курсу «Архітектура комп'ютерів» (кафедра ЕОМ, ІКТА, НУ «Львівська політехніка»).

Поведінку ядра відтворено з оригінальної програми `MicrocontrollerSimulator64` декомпіляцією бінарника. Файли програм `.txt` сумісні з оригіналом.

- **Десктоп**: Windows / macOS / Linux (Tauri 2)
- **Веб**: статичний сайт, працює без встановлення

## Інтерфейс

Інтерфейс зроблено як передню панель міні-ЕОМ:

- **Регістри.** PC та IR показано рядками світлодіодів, R0, R1 і R2 — на семисегментних індикаторах.
- **Сигнальні лампи:** Готово, Очікування, Виконання, Стоп, Збій.
- **Лампи тактів.** Показують, на якій мікрооперації зараз команда.
- **Пульт введення.** Тумблери адреси та 15 тумблерів даних, кольорові групи OP / A0 / A1 / A2, як на PDP-8. Працює в режимі редагування.
- **Клавіші керування** Редактор / Такт / Крок / Пуск і поворотний перемикач швидкості. Перемикач крутиться мишею, коліщатком або стрілками.
- **Пам'ять.** Матриця світлодіодів 16×15. Лампа шини показує, яку комірку такт вибрав, прочитав чи записав.

## Структура

| Шлях | Що це |
|---|---|
| `sim-core/` | Ядро на Rust без залежностей: пам'ять, мікротакти, перевірка програми, формат файлів. Покрите тестами. |
| `sim-wasm/` | Обгортка `wasm-bindgen`. Ядро працює як WebAssembly і у вебі, і в десктопі. |
| `app/` | Інтерфейс: React 19 + TypeScript + Vite + Tailwind CSS v4 |
| `app/src-tauri/` | Десктопна оболонка Tauri 2: нативні діалоги Відкрити / Зберегти |

## Розробка

Потрібні Rust (stable), Node.js 20+, `wasm-pack` і ціль `wasm32-unknown-unknown`:

```bash
rustup target add wasm32-unknown-unknown
```

```bash
cargo install wasm-pack
```

```bash
npm install
```

Далі:

```bash
npm run dev            # веб-версія на http://localhost:5173
```

```bash
npm run desktop        # десктопна версія (Tauri)
```

```bash
npm test               # тести ядра
```

```bash
npm run build:web      # статична збірка в app/dist
```

```bash
npm run build:desktop  # інсталятори в target/release/bundle
```

## Модель машини

- 16 комірок пам'яті (адреси `0000`…`1111`). Команди й дані лежать в одній пам'яті, і комірка вважається командою лише тоді, коли на неї вказує PC.
- Команда: `OOO AAAA AAAA AAAA` = код операції, A0, A1, A2.
- Регістри: PC, IR (регістр команд), R0, R1, R2.

| Код | Мнемоніка | Дія | Мікротакти |
|---|---|---|---|
| `000` | MOV | `[A2] = [A0]` | команда → R0 → R2=R0 → запис R2 → PC++ |
| `001` | ADD | `[A2] = [A0] + [A1]` | команда → R0 → R1 → R2=R0+R1 → запис R2 → PC++ |
| `010` | DIV | `[A2] = [A0] / [A1]` (цілочисельне) | … |
| `011` | SUB | `[A2] = \|[A0] − [A1]\|` | … |
| `100` | JE | якщо `[A0] == [A1]`, то PC = A2 | команда → R0 → R1 → R0<>R1 → PC=A2 / PC++ |
| `101` | MUL | `[A2] = [A0] * [A1]` | … |
| `110` | JG | якщо `[A0] > [A1]`, то PC = A2 | … |
| `111` | STOP | зупинка і вивід A0, A1, A2 та їхніх значень на екран | команда → R0 → R1 → R2 → Стоп |

- **Такт** (F3, T) виконує одну мікрооперацію. **Крок** (F4, S) виконує команду до кінця. **Пуск** (F5, R) виконує програму до STOP, миттєво або анімовано.
- Запуск заблоковано, доки програма не має досяжного STOP. Алгоритм перевірки перенесено з оригіналу без змін.

### Що уточнено за оригінальною програмою (у методичці цього немає)

- Перехід іде на **адресу** A2, а не на `[A2]`, хоча в довідці програми написано «goto [A2]».
- STOP не змінює PC.
- Результати не обрізаються до 15 біт: комірка зберігає 32-бітне ціле. 20000 + 20000 дасть 40000, у бітовій сітці буде видно лише молодші 15 біт, і з'явиться позначка «>15 біт». Файл зберігає лише 15 біт.
- Ділення на нуль аварійно завершує оригінальну програму. Тут воно зупиняє виконання з повідомленням.
- Нескінченний цикл оригінал не перериває. Тут Пуск зупиняється після 10 000 команд.
- Формат файлу: 16 рядків `AAAA : OOO AAAA AAAA AAAA`, не більше 511 байт.
